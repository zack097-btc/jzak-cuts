# libs

The three libraries build.py stitches into index.html. Edit them here, then run build.py from the repository root.

jzaktrace.js is our own tracing engine, written for this app and MIT licensed. opentype.min.js parses TrueType and OpenType files so uploaded fonts become real outlines (MIT). clipper.js does the polygon boolean work behind weld, subtract and contour cut (Boost Software Licence).

All three are permissively licensed, which is the reason this app can be sold. See LICENSES.md in the folder above.
